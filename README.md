# 현모 팬사이트 설치 안내

이 폴더를 GitHub Pages에 올리고 Firebase를 연결하면, 누구나 로그인 없이 볼 수 있는 팬사이트가 돼요.
천천히 따라 하면 30분 정도 걸려요. 돈은 들지 않아요.

| 파일 | 하는 일 |
| --- | --- |
| `index.html`, `style.css`, `app.js` | 사이트 본체 (고칠 필요 없어요) |
| `i18n.js` | 4개 언어 문구와 발매곡 목록 |
| `firebase-config.js` | ★ Firebase 설정값을 붙여넣는 곳 |
| `firestore.rules` | ★ Firebase 보안 규칙 (콘솔에 붙여넣기) |
| `music/playlist.js` | 노래 플레이어 목록 |

---

## 1단계. GitHub에 사이트 올리기

1. https://github.com 에서 가입하고 로그인해요.
2. 오른쪽 위 **+ → New repository**를 눌러요.
   - Repository name: `hyunmo` (원하는 이름 가능)
   - **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 압축을 푼 폴더 안의 파일과 `music` 폴더를 **전부 끌어다 놓고**, 아래 **Commit changes**를 눌러요.
5. 저장소의 **Settings → Pages**로 가서
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
6. 1~3분 뒤 같은 화면 위쪽에 사이트 주소가 떠요. 예: `https://내아이디.github.io/hyunmo/`

이 상태에서도 사이트는 보이지만, 응원 메시지·영상·라이브 기능은 아래 Firebase를 연결해야 작동해요.

## 2단계. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 **구글 계정**으로 로그인해요.
2. **프로젝트 만들기** → 이름 `hyunmo-fan` → Google 애널리틱스는 꺼도 돼요 → 만들기.
3. 프로젝트 첫 화면에서 **웹 아이콘 `</>`**를 눌러 앱을 등록해요. (호스팅 체크는 하지 않아요)
4. 화면에 나오는 `firebaseConfig = { apiKey: ... }` 값을 복사해요.
5. GitHub 저장소에서 `firebase-config.js` 파일을 열고 **연필(✏️) 아이콘** → `여기에_붙여넣기` 자리를 복사한 값으로 바꾸고 **Commit changes**.

## 3단계. 로그인 방식 켜기

1. Firebase 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭에서 두 가지를 켜요.
   - **익명** → 사용 설정 → 저장 (팬들이 로그인 없이 메시지를 쓰는 데 필요해요)
   - **Google** → 사용 설정 → 지원 이메일 선택 → 저장 (관리자 로그인용)
3. **설정 → 승인된 도메인 → 도메인 추가**에 `내아이디.github.io` 를 넣어요.

## 4단계. 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)**, **프로덕션 모드**로 시작해요.
3. **규칙** 탭을 열고, 원래 내용을 지운 뒤 `firestore.rules` 파일 내용을 **통째로 붙여넣고 게시**를 눌러요.

## 5단계. 관리자 등록하기 (라이브 버튼, 영상 추가)

1. Firestore **데이터** 탭 → **컬렉션 시작** → 컬렉션 ID: `admins`
2. 문서 ID에 관리자의 **구글 이메일 주소**를 그대로 써요. 예: `hyunmo@gmail.com`
3. 필드는 아무거나 하나 넣어요. 예: `role` / 문자열 / `admin` → 저장
4. 현모 님, 나, 운영진 등 관리자마다 문서를 하나씩 추가해요. 빼고 싶으면 그 문서를 지우면 돼요.

> 관리자는 **구글 계정**으로 로그인해요. 네이버 메일은 쓸 수 없으니, 현모 님께 사용할 구글(gmail) 주소를 받아서 등록해주세요.

## 사용 방법

- **관리자 로그인**: 사이트 맨 아래 **"관리자 로그인"** → 구글 계정 선택.
  등록된 관리자라면 라이브 버튼과 영상 추가 칸이 나타나요. 한 번 로그인하면 그 휴대폰·브라우저에서는 계속 유지돼요.
- **라이브 알림**: 이름 아래 **라이브 시작 알리기** → 모든 방문자 화면이 바로 반짝여요. 끝나면 **라이브 끝내기**. 깜빡해도 6시간 뒤 자동으로 꺼져요.
- **틱톡 영상**: 브라우저에서 연 틱톡 영상 주소(`.../video/숫자`)를 넣으면 사이트 안에서 바로 재생돼요.
  앱에서 복사한 짧은 링크(`vt.tiktok.com/...`)는 누르면 틱톡으로 이동하는 카드로 보여요.
- **응원 메시지**: 방문자는 로그인 없이 브라우저마다 메시지 하나를 남기고 고칠 수 있어요. 관리자는 아무 메시지나 지울 수 있어요.

## 노래 플레이어 켜기

1. GitHub 저장소의 `music` 폴더로 들어가 **Add file → Upload files**로 mp3 파일을 올려요. 파일 이름은 영어로 해주세요. 예: `green-dream.mp3`
2. `music/playlist.js`를 연필 아이콘으로 열고, 예시 줄 앞의 `//`를 지우고 파일 이름에 맞게 고쳐요.
3. 저장하면 1~2분 뒤 "♪ 현모 노래 듣기" 버튼이 생겨요. 브라우저 정책상 방문자가 버튼을 눌러야 재생이 시작돼요.

## 자주 묻는 것

- **사이트가 안 바뀌어요** → GitHub에서 저장한 뒤 1~3분 기다리고, 새로고침해보세요.
- **"관리자로 등록되어 있지 않아요"가 떠요** → `admins` 문서 ID가 로그인한 구글 이메일과 똑같은지 (대소문자 포함) 확인해요.
- **구글 로그인 창이 바로 닫혀요** → 3단계의 승인된 도메인에 `내아이디.github.io`를 넣었는지 확인해요.
- **비용** → 무료 요금제(Spark)로 하루 수만 명 방문까지 충분해요.
- **이상한 메시지가 올라와요** → 관리자로 로그인해서 그 메시지의 "삭제"를 누르세요.
